# V6 Work Shell — design & motion specification

V6 is the second, opt-in design language in `@mcky/ui`. V5 Paper Pop stays
available and unchanged through `@mcky/ui/core.css`. V6 is the language used by
Work Shell, the vaultctl web SPA, the mem wiki UI, and the Attendance Terminal.

- **Tokens & primitives:** `src/styles/v6.css` (`@mcky/ui/v6.css`)
- **Motion, decoration & transitions:** `src/styles/v6-motion.css`
  (`@mcky/ui/v6-motion.css`, also re-exported by `v6.css`)
- **Light/dark palette:** `src/styles/v6-theme.css` (`@mcky/ui/v6-theme.css`)
- **Animated backdrop:** `src/lib/components/Scenery.svelte` (`@mcky/ui/scenery`)
- **Optional scripted motion:** `src/lib/motion.ts` (`@mcky/ui/motion`)
- **Mode helper & toggle:** `src/lib/theme.ts` (`@mcky/ui/theme`),
  `src/lib/components/ModeToggle.svelte` (`@mcky/ui/mode-toggle`)
- **Reference surface:** `v6.html` (built by `npm run build:playground`)

The motion layer is extracted from the Attendance Terminal design system
(`github.com/ktypez/attendance-app`) and the Work Shell surfaces, then
normalised so a shared library can ship it safely.

## 3. Motion principles

1. **Transitions for interactive state, keyframes for one-shot sequences.**
   Hover, press and selection use transitions so they retarget mid-flight.
   Toasts, entrances and confetti use keyframes and run once.
2. **Press scales to 0.96 over 150ms**, and never on a disabled control.
3. **Hover effects exist only under `@media (hover: hover)`** so a tap on touch
   cannot leave a state latched.
4. **Entrances are staged 100ms apart** — opacity, 4px blur and 12px
   `translateY` over 300ms. Exits are shorter (150ms) and smaller.
5. **Reduced motion is honoured everywhere.** Every movement is neutralised and
   replaced with an opacity cross-fade; the state change always keeps a static
   cue (color, icon or label), so motion is never the only feedback.
6. **Only the changing properties are transitioned** — never `transition: all`.
7. **Suppress transitions on theme swap** with `withoutTransitions()` so colors
   do not smear.

## 5. Utility classes

**Transitions**

- `.mcky-v6-lift` — hover raises −2px with the 8px shadow; press scales 0.96.
- `.mcky-v6-tilt` — like lift plus a −1deg rotation.
- `.mcky-v6-press` — press-only scale.

**Decoration**

- `.mcky-v6-canvas` — drifting clouds behind the content (add ambient).
- `.mcky-v6-dotted` / `.mcky-v6-dotted-light` — dotted paper texture.
- `.mcky-v6-rule` — mono label followed by an ink rule.
- `.mcky-v6-strip` — left accent strip (`--mcky-v6-strip-color`).
- `.mcky-v6-dot-live` (+ `--ok` / `--warn` / `--error`) — pulsing status dot.
- `.mcky-v6-spark` (+ `--delay`) — twinkling sparkle.
- `.mcky-v6-orbit` — slow dashed orbit ring.
- `.mcky-v6-float` (+ `--slow` / `--delay`), `.mcky-v6-bob` — ambient drift.
- `.mcky-v6-loading-bar`, `.mcky-v6-spin`, `.mcky-v6-shimmer`.

**One-shot**

- `.mcky-v6-enter`, `.mcky-v6-enter-pop`, `.mcky-v6-stagger > *`.
- `.mcky-v6-toast-stack`, `.mcky-v6-toast` (+ `--success` / `--error` /
  `--warning` / `--out`).
- `.mcky-v6-overlay` (pop-in, contained scroll), `.mcky-v6-confetti-layer` /
  `-piece`.

**Theme switch** — add `data-v6-no-transition` to `<html>` for one frame, or
call `withoutTransitions()`.

## 6. Scripted helpers (`@mcky/ui/motion`)

```ts
import { burstConfetti, prefersReducedMotion, withoutTransitions } from '@mcky/ui/motion';

burstConfetti({ count: 140, spread: 80, origin: { y: 0.6 } });
```

- Dependency-free (no `canvas-confetti`), SSR-safe, and a no-op under reduced
  motion.
- `withoutTransitions(update)` applies a theme change without color smear.

## 7. Light/dark mode

`@mcky/ui/theme` is framework-free and SSR-safe:

```ts
import { applyV6Mode, setV6Mode, toggleV6Mode, onV6ModeChange } from '@mcky/ui/theme';

applyV6Mode();          // resolve the stored preference at startup (default: auto)
setV6Mode('dark');      // persist to localStorage under mcky-v6-mode
toggleV6Mode();         // flip light/dark based on the painted mode
onV6ModeChange((mode) => console.log(mode));
```

`auto` resolves from `prefers-color-scheme: dark` and stays subscribed to OS
changes; `light` and `dark` are absolute. The helper writes
`<html data-v6-mode="…">` and `color-scheme` through `withoutTransitions()` so
colors do not smear. Svelte apps can use `<ModeToggle />` from
`@mcky/ui/mode-toggle` instead of wiring their own button.

## 8. Animated backdrop

`<Scenery />` is ported from the Portal implementation, not reimagined: both
apps render the same clouds, hills, trees, stars, moon and skyline. Mount it
once as an inert sibling of the app root; content sits in a sibling with
`.mcky-v6-scenery-content` (position relative, z-index 1):

```svelte
<script>
  import Scenery from '@mcky/ui/scenery';
</script>

<Scenery />
<main class="mcky-v6-scenery-content">
  <section class="mcky-v6-canvas mcky-v6-card">
    <div class="mcky-v6-rule">RECENT SHIFTS</div>
    <button class="mcky-v6-button mcky-v6-lift">Open</button>
    <span class="mcky-v6-spark">✳</span>
  </section>
</main>
```

- **Day:** three ☁️ glyphs (3.2rem / 2.6rem / 2rem, 45% opacity, 7s float with
  2.5s and 4s offsets), a gold sun, two hills, two trees and nine grass tufts.
- **Night:** twelve staggered twinkling stars, a crescent moon and ten buildings
  with 29 lit windows.
- The view follows the shared V6 mode, or a pinned `mode="day" | "night"` prop
  (Portal uses this to keep its existing `portal-mode` storage key). All loops
  stop under `prefers-reduced-motion: reduce`.

`references/portal/scenery.snapshot.svelte` is the checked-in Portal reference;
`test/v6-theme.test.mjs` fails if the shared data arrays drift from it.

## 9. Usage

```css
@import '@mcky/ui/v6.css';        /* tokens, primitives, theme and motion */
/* or import only the CSS layers you need: */
@import '@mcky/ui/v6-theme.css';
@import '@mcky/ui/v6-motion.css';
```

## 10. Consumer references

Before changing tokens, the theme ramp or the shared scenery/toggle, read the
matching note under [`references/`](./references/README.md). The manifest and
notes cover Portal, Truck, Data, Dashboard, Work Shell, mem web and vaultctl
web: their stack, pinned version, local overrides, theme keys, scenery, apply
checklist and verification commands. `test/references.test.mjs` checks the
registry; Portal's scenery/toggle are snapshotted so the shared copies cannot
drift from production.
